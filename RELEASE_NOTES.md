# Dynamic Time Board v1.1.0

## Highlights
- Bilingual user interface (English default, Chinese selectable).
- Four rolling day groups: Today, Next 7 Days, Days 8–30, Beyond 30 Days.
- Task schedule first; deadline fallback with explicit notice when no execution plan is set.
- Deadline alerts configurable for 1, 3 or 7 local calendar days (default: 3).
- Task card project tags in the upper-right, separate plan and deadline rows, no splitting time tokens.
- Consistent expand/collapse panels, optional help text, saved UI preferences where supported.
- Read-only task/project operations.

## Installation
Download `SuperProductivity_DynamicTimeBoard_v1.1.0.zip` from Release Assets and install it from Super Productivity → Settings → Plugins.

## Tested
Manually tested on Super Productivity 19.3.1W (Windows). Other versions/platforms are not systematically tested.

## Known limitations
Standalone Planner calendar data is not fully available to the plugin API. Deadline-only tasks use a transparent fallback placement, not an execution plan. Estimated overruns depend on available schedule time and estimated duration.
