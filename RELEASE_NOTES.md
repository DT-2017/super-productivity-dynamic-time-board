# Dynamic Time Board v1.0.0

First public test release.

- Automatic due-date buckets: Today (including overdue), This Week, This Month, Future
- Separate undated-task area
- Project filter and manual refresh
- Periodic refresh and automatic recategorization on local date change
- Read-only interface; does not modify task data

**Limitations:** Uses due dates rather than Planner scheduled dates; completed tasks and subtasks are omitted. UI is in Chinese. Feedback and bug reports are welcome.
